# Web UIの実装

## コンポーネントと配置

- Basecoat UIをベースに、標準のコンポーネント・配色・タイポグラフィを使います。
- 用途に応じて標準variantを選び、hover・focus・disabledなどの状態表現もBasecoatに委ねます。
- 配置・余白・レスポンシブ対応を含む微調整には、Tailwindのクラスを使います。
- コンポーネントは自身の内部レイアウトを定義し、親・兄弟との配置や余白は親側で定義します。
- ブランド表現とBasecoat標準との差分は、各プロジェクトのデザイン資料を参照します。

## フォント

- デフォルトのフォントにはNoto Sans JPを使います。

## アイコン

- Tabler Iconsの公式SVGを使い、同じ意味のアイコンを統一します。
- 文字記号・絵文字・CSS図形・独自SVGで代用しません。

## アクセシビリティ

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)のレベルAAを実装・検証の基準とします。
- 個別の達成基準・実装方法は、[クイックリファレンス](https://www.w3.org/WAI/WCAG22/quickref/)を、変更の影響範囲に応じて参照します。
