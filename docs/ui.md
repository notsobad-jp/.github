# Web UIの実装

## コンポーネントと配置

- Basecoat UIの標準コンポーネント・配色・タイポグラフィを使います。
- 用途に応じて標準variantを選び、hover・focus・disabledなどの状態表現もBasecoatに委ねます。
- TailwindのクラスをHTMLに付与し、配置・余白・レスポンシブ対応を定義します。
- コンポーネントは自身の内部レイアウトを定義し、親・兄弟との配置や余白は親側で定義します。
- ページはセクション単位のコンポーネントを組み立てます。
- ブランド表現とBasecoat標準との差分は、各プロジェクトのデザイン資料を参照します。
- 個別の要素の色・サイズ・配置・variantは実装を正本とし、規約に列挙しません。

## アイコン

- Tabler Iconsの公式SVGを使い、同じ意味のアイコンを統一します。
- 文字記号・絵文字・CSS図形・独自SVGで代用しません。
- 追加・変更したアイコンは、完了前に公式SVGとの一致を確認します。

## 情報階層とレスポンシブ対応

- ページ・セクション・本文の情報階層を明確にし、独立したまとまりは余白で分けます。
- 枠線はまとまりの境界に使います。
- 画面幅や文字量が変わっても、内容と操作が画面からはみ出さないようにします。
- 省略表示を使う場合は、必要な情報の全文を確認できる導線を確保します。
